# labs/ — Saturday lab work

One folder per lab, named after its ID in `TRACKER.md` (e.g. `labs/LAB01-rate-limiter/`).

- **Where:** mostly on the personal laptop (full tooling: Docker, Redis, Postgres, etc.).
  On the work laptop only when a lab runs on stdlib Python + uv; anything else is marked ⚙.
- **Sync:** `git pull` before you start, `git add -A && git commit && git push` when you stop,
  so the other laptop always has the latest.
- Lessons (`lessons/`) teach the pattern; labs apply it to something bigger.
